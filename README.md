# 💰 AI Money Mentor

## 🚀 Overview

AI Money Mentor is a full-stack fintech application that helps users manage personal finances intelligently. It provides insights on savings, tax optimization, financial health, investment planning, and portfolio analysis.

---

## ✨ Key Features

### 🔥 FIRE Path Planner

* Calculates Financial Independence target
* Monthly investment roadmap
* SIP suggestions
* Asset allocation strategy
* Insurance gap detection

### 📊 Money Health Score

* Emergency preparedness
* Insurance coverage
* Investment diversification
* Debt health
* Tax efficiency
* Retirement readiness

### 🎯 Life Event Advisor

* Personalized advice for events like marriage, baby, bonus
* Risk-based investment suggestions

### 💸 Tax Wizard

* Old vs New regime comparison
* 80C, 80D, HRA deductions
* Tax-saving recommendations

### 👩‍❤️‍👨 Couple Planner

* Combined savings & FIRE planning
* Joint financial insights

### 📊 Portfolio X-Ray (Advanced)

* CSV-based portfolio upload
* XIRR calculation
* Asset allocation breakdown
* Expense ratio analysis
* Benchmark comparison
* AI-based rebalancing suggestions

---

## 🛠 Tech Stack

### Frontend

* React.js
* Tailwind CSS

### Backend

* FastAPI (Python)

### Data Processing

* Pandas

---

## ⚙️ Installation

### Backend

```bash
cd backend
pip install fastapi uvicorn pandas
python -m uvicorn main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm start
```
